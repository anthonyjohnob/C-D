# C/D — corneal drawing

**Live site: https://anthonyjohnob.github.io/C-D/**

Draw corneal ulcers and other corneal pathology in the standard slit-lamp colour code. Trace the epithelial
defect and infiltrate with a finger, carve stromal thinning in cross-section, and get width × height
dimensions, the 1-2-3 rule, culture results with sensitivities, a printable summary sheet and an
auto-written clinical note. Any drawing can be shared as a QR code that redraws it on another device,
with or without an internet connection. At a follow-up visit, scan last visit's code (or press Follow-up)
and update each finding step by step; C/D shows what changed and whether the ulcer is improving.

- Runs entirely in the browser. Nothing you draw, type or photograph is uploaded; there are no accounts, analytics or cookies.
- Works offline after the first visit, and can be added to a phone or tablet home screen.

**Intended use:** education and documentation by eye-care professionals and trainees. Not medical advice.
C/D does not diagnose, treat or replace an examination, and it is not for patients making decisions about
their own care.
